# SkillTwin — Final Demo Video Script

Target length: **4–6 minutes**

## 0:00–0:20 — Problem and one-line pitch

**Screen:** Landing page

**Narration:**

> Most learning platforms give you a static roadmap. SkillTwin is different: it maintains an evidence-backed digital twin of your skills and adapts your learning plan whenever new evidence proves that your state has changed.

Show the landing hero and quickly point to:
- evidence-backed learner model
- adaptive roadmap
- Challenge Me
- explainable plan changes

## 0:20–0:45 — Start with a learner

**Screen:** Sign in / onboarding

> I’ll start with a learner account and choose a target career. SkillTwin does not assume missing evidence means low skill; it starts unknown and waits for evidence.

Choose a target role and learning constraints.

## 0:45–1:30 — Add evidence

**Screen:** Onboarding / evidence

Add one of:
- text-based PDF resume
- project evidence
- manual profile evidence

> SkillTwin converts profile information into evidence proposals, maps them to the canonical skill taxonomy, and then the deterministic Evidence Engine updates the learner state.

Show:
- onboarding progress
- SkillTwin creation
- readiness/evidence coverage

## 1:30–2:05 — Show the SkillTwin

**Screen:** Skills

> This is the learner’s current SkillTwin. Capability and confidence are separate, and every state is backed by evidence.

Show:
- Skill Graph
- one skill detail
- evidence
- current level/confidence

Then open **Home** and show role readiness / focus.

## 2:05–2:40 — Adaptive roadmap

**Screen:** Plan

> SkillTwin compares the learner against the target-role model and creates a constrained roadmap with Learn, Practice, Build and Validate tasks.

Open a task and point out:
- duration
- verified resource
- task type
- completion state

## 2:40–3:35 — Challenge Me

**Screen:** Practice

Start Challenge Me.

> Instead of assuming a learner understood the content, SkillTwin validates it.

Answer the assessment.

While the final answer is processing:

> The final submission commits assessment evidence, updates the SkillTwin, recalculates gaps and evaluates whether the future plan should change.

## 3:35–4:20 — Show the agent actually adapting

**Screen:** Assessment result / See What Changed

Show:
- score
- SkillDelta
- capability/confidence change
- readiness/evidence update

Open **See What Changed**.

> SkillTwin does not regenerate the entire roadmap. It creates the smallest safe PlanDiff for future work.

Show:
- old plan version -> new plan version
- added/moved/changed task
- reason
- undo availability

## 4:20–4:50 — Grounded explanation

**Screen:** Ask SkillTwin

Ask:

**“Why did my roadmap change?”**

> Journey Chat is grounded in persisted learner state. It can explain the change using the actual gap, evidence and task references rather than inventing an answer.

Show the grounded response.

## 4:50–5:10 — Audit trail

**Screen:** Agent Activity

> Every important agent action is auditable.

Show events such as:
- skill updated
- gap analysis completed
- assessment completed
- plan adapted

## 5:10–5:30 — Close

**Screen:** Landing page or Overview

> SkillTwin closes the loop between learning and proof. It observes evidence, updates the learner model, plans the next action, validates progress and adapts only when the evidence justifies it.

End with:

**SkillTwin — learn, prove, adapt.**

## Recording checklist

- Use a fresh evaluator/test account
- Keep browser zoom at 100%
- Close unrelated tabs
- Disable notifications
- Use 1080p recording
- Keep cursor movement deliberate
- Do not wait silently during long processing; narrate what the agent is doing
- Do not expose API keys, database URLs, personal email, or private credentials
- Upload to YouTube as **Unlisted**
- Test the final video link in incognito mode
