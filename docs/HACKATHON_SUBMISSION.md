Suggested text for the form:

> SkillTwin is an evidence-backed adaptive learning agent that builds a persistent learner model from resume, project, task and assessment evidence. It compares the learner against a target-role model, computes role-relative gaps, generates a constrained learning roadmap, validates skills through adaptive assessments, and updates both the learner model and future roadmap when new evidence justifies a change.
>
> Core agent loop: **Evidence -> SkillTwin -> Gap Analysis -> Adaptive Plan -> Challenge Me -> SkillDelta -> Gap Refresh -> PlanDiff -> Explainable Updated Plan.**
>
> The system includes deterministic server-owned learner state, confidence/capability separation, verified learning resources, adaptive assessment, minimal versioned replanning, Journey Chat grounded in persisted state, Agent Activity audit events, Supabase RLS/private storage, and production release QA.
